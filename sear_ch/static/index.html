    Guide

    How Search works

    Search runs through your backend, with optional local AI.

    Search starts here

    Your query goes to this sear_ch server, then to the selected search provider such as SearXNG.

    Results get organized

    sear_ch formats web, news, image, and map results into the current view, using your filters, engines, language, and time range.

    Local hints are optional

    Your ZIP code can bias places, maps, and local news. Map tiles and directions use OpenStreetMap.

    AI is added only when enabled

    When AI is on, sear_ch sends prompts, selected result snippets, chat context, and model settings to Ollama for summaries and answers.

    You stay in control

    Settings control the provider, filters, autocomplete, AI model, response length, and source limits.

    Check important results

    Search results and AI summaries can be incomplete or wrong, so use original sources before making important decisions.

    Privacy

    Privacy and safety

    Preferences save in this browser; chat history saves only when enabled.

    What is saved here

    A browser preferences record stores theme, view, ZIP, provider, filters, engines, autocomplete, search on/off, and AI settings.

    Chat history

    AI Chat is memory-only by default. If browser saving is enabled, a separate chat record stores up to 20 chats and 80 recent messages per chat.

    What gets sent

    Search and autocomplete requests go to this sear_ch server, then to the configured search service. AI prompts, selected result snippets, chat context, model settings, and source limits go through this server to Ollama when AI is enabled.

    Outside services

    Page previews are fetched by this server. Map tiles, directions, opened results, image sources, and remote thumbnails can contact external sites directly from your browser.

    What sear_ch does not use

    sear_ch itself does not use accounts, cookies, IndexedDB, sessionStorage, analytics profiles, or a server-side database for your searches and settings.

    Deleting saved data

    Use Reset defaults, Delete chat, Memory only chat history, or clear this site’s browser data. Browser history and external service logs are separate.

    For stronger network privacy, use a trusted system VPN. Privacy also depends on your configured search service, AI service, VPN provider, browser, and network setup.

    Closing sear_ch does not erase saved browser data.
